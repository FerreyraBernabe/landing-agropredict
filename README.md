# AgroPredict <·> Azahar

AgroPredict es una empresa dedicada al desarrolo de software especializado para apoyar tareas de _Agricultura de Precisión_
Nuestro producto principal, llamado Azahar, consiste en un mapa de las fincas de nuestros clientes con todos los parámetros que a ellos les interesa observar. Cada uno de sus lotes tiene asociado un dashboard con alertars, reportes, un calendario y cualquier otro aspecto que resulte importante para ellos.
